# Telegram Mini App «Токен» (Clicker & Mini-Games)

Полнофункциональный Telegram Mini App-кликер с единой внутриигровой валютой **Токен**, прокачкой дохода за клик, 4 мини-играми с криптографической честностью (Provably Fair SHA-256), мультиплеерным Crash, P2P-переводами по @username и Telegram-ботом на grammY.

---

## 🌟 Ключевые возможности

1. **Главный экран и 3D-монета:**
   - Интерактивная металлическая монета с эффектом золотого обода, градиентными текстурами и динамическими бликами.
   - Плавное покачивание и вращение в режиме ожидания.
   - Физика тапа: мгновенное сжатие на 3–5%, вылет партиклов `+0.001` в месте клика и тактильный отклик Telegram Haptic Feedback.
   - Отображение баланса минимум с 3 знаками после запятой: `0.000 Токен`.

2. **Upgrader (Прокачка дохода за клик):**
   - Прогрессия уровней: `0.001 → 0.002 → 0.004 → ... → 25.000` Токенов за тап.
   - Моментальное списание баланса и увеличение доходности.

3. **4 Мини-игры (порог входа: 5 Токенов):**
   - **Crash (Мультиплеер в реальном времени):**
     - Единая комната для всех игроков онлайн, плавный рост кривой множителя.
     - Список активных ставок и вывод выигрыша кнопкой «ЗАБРАТЬ».
     - История последних исходов.
   - **Самолётик:**
     - Аркадный полёт 5–8 секунд.
     - Пролёт сквозь кольца (зелёный импульс, множитель ×1.5).
     - Уклонение от ракет (красный импульс, множитель ÷1.5, не ниже 1.00x).
     - Посадка на полосу (шанс 75%).
   - **Random:**
     - Быстрый выбор с открытыми вероятностями (100% сумма):
       `×0 (35%)`, `×0.5 (25%)`, `×1 (20%)`, `×1.5 (10%)`, `×2 (6%)`, `×3 (3%)`, `×5 (1%)`.
   - **Больше / Меньше:**
     - Числа от `0` до `999999` (1 000 000 исходов).
     - Регулировка шанса ползунком `1.00% – 95.00%`.
     - Комиссия сервера 1% (`Множитель = 99 / шанс`).
     - Электронный шестизначный барабан прокрутки чисел.

4. **Криптографическая честность (Provably Fair SHA-256):**
   - Сервер публикует хэш Server Seed до совершения ставки.
   - Исход рассчитывается детерминированно: `HMAC-SHA256(ServerSeed, ClientSeed + Nonce)`.
   - Раскрытие Server Seed после раунда.
   - Встроенный калькулятор проверки честности прямо в интерфейсе!

5. **P2P-переводы по @username:**
   - Отправка токенов по `@username` с подтверждением.
   - Идентификация пользователей по неизменному Telegram User ID.
   - Детальная история входящих и исходящих транзакций.

6. **Двойной режим запуска:**
   - В Telegram: автоматическая авторизация через валидацию `initData` ключом бота.
   - В браузере (ПК/мобильный): автоматический Dev-режим с кнопкой быстрого переключения между игроками для локального тестирования.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
В корне проекта:
```bash
# Установка зависимостей клиента
cd client
npm install
cd ..

# Установка зависимостей сервера
cd server
npm install
cd ..
```

### 2. Настройка Telegram-бота (опционально)
Откройте файл `server/.env` и укажите данные вашего бота из [@BotFather](https://t.me/BotFather):
```env
PORT=3001
HOST=0.0.0.0
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
WEBAPP_URL=https://your-domain.com # или адрес туннеля (ngrok / localtunnel)
```
> *Если `BOT_TOKEN` не указан, сервер автоматически работает в локальном Dev-режиме, позволяя тестировать приложение в браузере без Telegram.*

### 3. Сборка и запуск

Собрать клиент и сервер:
```bash
npm run build:client
npm run build:server
```

Запустить сервер:
```bash
npm start
```
Сервер будет доступен по адресу: `http://localhost:3001` (раздаёт как API, так и скомпилированный веб-интерфейс).

Для разработки с Hot-Reload (горячей перезагрузкой):
```bash
# В терминале 1 (сервер):
npm run dev:server

# В терминале 2 (клиент):
npm run dev:client
```
Client dev server: `http://localhost:5173`
Backend server: `http://localhost:3001`

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Backend:** Node.js, Fastify, TypeScript, Server-Sent Events (SSE).
- **База данных:** SQLite (встроенный высокопроизводительный движок `node:sqlite` с WAL-режимом).
- **Бот:** grammY (официальный фреймворк Telegram Bot API).
- **Криптография:** Web Crypto API / Node crypto (HMAC-SHA256).
